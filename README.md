# JWA

오픈소스기초설계 | 20261733 좌상엽

이 저장소에서 과목 실습 소스와 보고서를 관리합니다.

- `src/`: 셸 프로그래밍 실습 10개 (`ex3-0.sh` ~ `ex3-9.sh`)
- `doc/`: 보고서 및 실제 실행 화면
- 실행 환경: Ubuntu, Bash. `awk`, `tar`, `top`, `free` 사용

PDF 4쪽과 5쪽의 ex3-5 요구사항을 하나로 통합했습니다. 인자 없이 실행하면 시스템 메뉴, 인자가 있으면 내부 함수의 `ls` 옵션으로 전달합니다.
성적은 90 이상 A, 미만 B입니다. 문제에 수치형 GPA 환산표가 없어 ex3-4도 같은 기준을 사용합니다.

## 실행
```bash
mkdir -p work
cd work
bash ../src/ex3-1.sh 12 5
bash ../src/ex3-2.sh
bash ../src/ex3-5.sh
bash ../src/ex3-5.sh -l ../src
```

환경변수 실습은 `source src/ex3-0.sh`로 실행합니다. `.bashrc`에 export를 등록하고 현재/자식 셸에서 확인한 뒤 unset합니다. unset은 현재 셸의 값을 해제하며, 새 대화형 셸에서는 `.bashrc`로 재설정됩니다.
파일 생성 실습은 작업용 빈 폴더에서 실행하세요. DB 실습의 `--new`는 현재 작업 폴더의 DB.txt를 새 내용으로 덮어씁니다. 보고서 예제에는 가상의 이름과 생일을 사용합니다.
